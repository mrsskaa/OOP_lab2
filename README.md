# OOP_lab2

Лабораторная 2 по ООП. Семейство B, вариант 8: класс `Polynomial`, производная и неопределённый интеграл. C++20, Google Test, AddressSanitizer.

## Структура

- `include/lab02/polynomial.hpp` — объявление класса.
- `src/polynomial.cpp` — реализация методов.
- `src/main.cpp` — пример использования.
- `test/polynomial_test.cpp` — 29 тестов.
- `CMakeLists.txt` — сборка библиотеки, программы и тестов.
- `.clang-format` — правила форматирования.

## Хранение и память

`coefficients_` — динамический массив `double`, `degree_` — степень многочлена. Массив `{1, 2, 3}` задаёт `1 + 2x + 3x²`: индекс коэффициента равен степени x. Старшие нули удаляются. Нулевой многочлен: `degree_ == -1`, `coefficients_ == nullptr`.

Конструктор выделяет память через `new[]`, деструктор освобождает через `delete[]` — это RAII. Копирование создаёт отдельный массив, перемещение забирает его за O(1), оставляя источник нулевым многочленом.

Копирующее и перемещающее присваивания объединены в `operator=(Polynomial other)` через copy-and-swap: параметр создаётся копированием или перемещением, затем обменивается данными с текущим объектом. Его деструктор освобождает старую память. Самоприсваивание безопасно; при ошибке выделения памяти получатель сохраняется.

## Методы

| Метод | Назначение |
| --- | --- |
| `degree()` | Степень многочлена |
| `operator[]` | Чтение коэффициента; неверный индекс вызывает `std::out_of_range` |
| `trim()` | Удаление старших нулевых коэффициентов |
| `add(other)` | Сложение коэффициентов одинаковых степеней |
| `mul(other)` | Умножение: `result[i + j] += a[i] * b[j]` |
| `evaluate(x)` | Значение многочлена по схеме Горнера |
| `print(out)` | Вывод многочлена |
| `derivative()` | Производная: `a[i] * i` записывается в позицию `i - 1` |
| `integral()` | Интеграл: `a[i] / (i + 1)` записывается в позицию `i + 1`; `C = 0` |

Производная и интеграл возвращают новые объекты, не меняя исходный. Примеры: `1 + 2x + 3x²` → `2 + 6x`; интеграл `2x` → `x²`.

## Сборка и запуск

Из папки проекта:

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug -DCMAKE_CXX_COMPILER=/opt/homebrew/bin/g++-16
cmake --build build -j 4
ctest --test-dir build --output-on-failure
./build/lab02_main
```

В CLion выбрать `/opt/homebrew/bin/g++-16` как C++ Compiler в Toolchains. Цель `lab02_main` запускает пример, `tests` — тесты. При первой настройке требуется интернет для загрузки Google Test, если он не установлен.

Тесты проверяют арифметику, производную, интеграл, нулевой многочлен, копирование, перемещение, самоприсваивание и ошибки аргументов. Все 29 тестов прошли с ASan; отдельная проверка macOS `leaks` показала 0 утечек.
